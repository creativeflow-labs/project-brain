# Project Brain 상용화 방향

> 확정일: 2026-07-31

## 핵심 정체성

> 피비는 팀의 업무를 기억하고 검증합니다.

Project Brain(PB, 피비)은 범용 AI 검색 SaaS가 아니라 고객 소유 환경에 구축하는 팀 단위 업무 검증 시스템이다. 흩어진 문서·이메일·업무 기록을 연결해 단순히 관련 내용을 찾는 데서 끝나지 않고 결정, 담당자, 금액, 변경 이유, 현재 상태를 원문 근거로 비교한다.

## 시장 포지션

### 목표 시장

- 5~30명 규모의 프로젝트팀 또는 전문 조직
- Notion·이메일·파일에 업무 정보가 흩어진 조직
- 외부 제안과 내부 결정, 과거 기록과 최신 기록이 자주 충돌하는 조직
- 대외비 자료를 범용 SaaS에 직접 올리는 것을 부담스러워하는 조직
- 전담 AI 개발팀은 없지만 팀 업무에 맞춘 구축·교육·튜닝이 필요한 조직

### 초기 비목표 시장

- 수백~수천 명이 동시에 사용하는 전사 범용 검색 플랫폼
- 수백 개 커넥터와 복잡한 전사 권한 체계가 즉시 필요한 조직
- 데이터 튜닝 없이 설치만으로 완성되는 저가형 문서 챗봇 시장
- 검증보다 단순 요약·작성 기능만 필요한 사용자

## 상품 구조

### 1단계: 유료 진단·컨설팅

- 팀 업무 흐름과 주요 질문 분석
- 데이터 출처·권한·민감도 확인
- 문서 기록 방식과 충돌 유형 진단
- 데모와 교육을 통한 적용 가능성 검토
- 구축 범위·합격 기준·예상 비용 확정

### 2단계: 고객 소유형 구축

- 기본 가설: 사용자 5명 기준 3천만 원부터 시작
- 고객 소유 서버 또는 고객이 승인한 전용 환경에 피비 구축
- Notion·이메일·파일 등 합의된 데이터 연결
- 검색·판정 튜닝, 팀별 표현 사전, 회귀 질문 세트 구성
- 사용자 교육과 관리자 운영 가이드 포함
- 사용자가 늘거나 연결·권한·업무 흐름 범위가 넓어지면 추가 비용 산정

가격은 소프트웨어 설치비가 아니라 데이터 연결, 검색·판정 튜닝, 교육, 인수 검증을 포함한 구축비다.

### 3단계: 버전·기능 고도화

- 상시 소액 유지보수 항목을 복잡하게 나누지 않는다.
- 신규 커넥터, 알림, 업무관리 연동, 권한 고도화 등 명확한 버전 업데이트 단위로 계약한다.
- 기능 묶음과 고객별 적용·재튜닝 범위를 기준으로 별도 비용을 산정한다.

## 경쟁 전략

### 구축형이라는 사실만으로는 차별화하지 않는다

셀프호스팅, 온프레미스, RAG, 벡터 검색, SSO·RBAC·감사 로그는 이미 구축형 플랫폼과 대형 SI가 제공하는 공통 역량이다. 피비의 경쟁력은 설치 위치가 아니라 팀 업무 검증의 깊이에서 만들어야 한다.

### 글로벌 제품을 기능 기준으로 사용한다

- Notion AI: 출처 범위 선택, 자연스러운 검색·답변 UX, 워크스페이스 문맥
- Glean: 권한 기반 검색, 최신성, 커넥터 운영, 검색 품질 평가와 관측성
- Atlassian Rovo: 사람·팀·프로젝트·업무 관계, 협업 도구 안의 검색 경험
- Microsoft 365 Copilot: 조직 계정, 원본 권한 상속, 감사·관리 체계

이 기능을 그대로 복제하지 않고 피비의 목표 고객에게 필요한 부분부터 선택적으로 반영한다.

### 피비가 독자적으로 강화할 코어

- 같은 사건에 관한 상충 기록 탐지
- 외부 담당자·내부 담당자·최종 승인자 역할 구분
- 상대 제안·우리 견적·내부 기록·최종 승인 금액 구분
- 제안·요청·승인·실행·완료·수정 요청의 상태와 시간축 판정
- 완료 주장과 실제 승인 구분
- 확인됨·충돌·근거 부족 판정과 원문 역추적
- 팀별 표현과 업무 규칙에 맞춘 데이터 튜닝

## 기능 고도화 우선순위

1. 검색 정확도와 재현율
2. 변경·삭제·최신성 동기화
3. 출처 선택형 검색
4. 사용자별 권한과 보안
5. 사건·사람·결정 관계 구조화
6. 업무 흐름과 상태 검증
7. 운영 모니터링과 평가 자동화
8. 팀장용 검증 브리핑·알림함
9. 승인 기반 업무 실행

## 유료 베타와 마이그레이션 게이트

Railway 마이그레이션은 기능 개발의 시작점이 아니라 로컬 유료 베타 준비도가 합격한 뒤 진행한다.

필수 기준:

- 유료 베타 종합 준비도 80점 이상
- 검색·판정 코어 85점 이상
- 보안·권한 70점 이상
- 잘못된 확정 답변 0건
- 충돌·근거 부족 누락 0건
- 대화 문맥과 프로젝트 격리 오류 0건
- 데이터 동기화 실패·재시도 상태 확인 가능
- 모바일 핵심 흐름에 차단 오류 없음
- 외부 조직 수준의 테스트 시나리오 통과
- 최종 답변 품질에 대한 대표 검수 승인

통과 이후 순서:

```text
로컬 유료 베타 기준 통과
  → 안정 버전 확정
  → Railway 비공개 마이그레이션
  → 배포환경 안정화
  → 네이버웍스 등 외부 채널 연결
```

## 장기 방어 자산

기술 스택 자체보다 다음 자산을 축적한다.

- 실제 업무 질문과 실패 사례 데이터셋
- 충돌·상태·시점·역할 판정 규칙과 평가 기준
- 업종·팀별 데이터 튜닝 매뉴얼
- 구축 전 진단 방법론
- 팀 교육 커리큘럼
- 고객 인수 테스트와 합격 기준
- 구축·재튜닝·버전 업데이트 운영 매뉴얼

교육은 부가 서비스가 아니라 고객 데이터를 이해하고 튜닝 기준을 확보하는 제품 개발 과정으로 운영한다.

## 영업 표현 원칙

지양:

> 사내 문서를 검색하는 맞춤형 AI 비서를 구축해드립니다.

사용:

> 피비는 팀의 업무를 기억하고 검증하는 고객 소유형 AI 시스템입니다. 흩어진 문서와 이메일을 연결해 결정, 담당자, 금액, 변경 이력과 현재 상태를 원문 근거로 확인합니다.
