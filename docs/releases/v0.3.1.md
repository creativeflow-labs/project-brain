## Project Brain v0.3.1

Notion 상하위 문서 연결과 검색 정확도·판정 안전장치를 보완한 공식 릴리스입니다. 사용자 검토를 거친 `v0.3.1-rc.1`의 기능을 유지하고 정식 버전으로 전환했습니다.

### 주요 변경

- Notion 상위 페이지·컬렉션의 제목과 경로를 하위 문서 검색에 반영
- 한국어 키워드 검색 결과가 0건일 때만 접두 일치 후보 보충
- 추출형 대체 답변에서 견적·제안·기록과 최종 합의 구분
- 제품 이름 질문을 사내 자료 검색에서 분리
- 앱·정적 자산·검색 추적의 버전 표기 통일

### 유지한 기능

- 기간·전체 목록용 컬렉션 전용 경로
- 후속 질문의 문맥과 프로젝트별 검색 범위
- 다중 출처 판정, 답변별 근거 스냅샷과 인용 전환
- 기존 모델·수집 구조 유지, 재임베딩 및 DB 스키마·인덱스 변경 없음

### 확인 및 한계

- 자동 테스트 67개 통과
- 실제 13개 순차 질문의 변경 전후 답변·인용 비교 및 사용자 검토
- 질문지는 회귀 확인용 샘플이며 모든 사용자 질문을 이 형태로 제한하지 않음
- 일반 질문의 응답 속도 개선은 확인되지 않음
- 질문 범위 확장, 부분 미확인 표현 및 역할 근거 확인은 후속 개선 예정
- 실제 업무 자료·인증 정보·로컬 질문 및 답변 기록은 Git 배포에서 제외
