## Project Brain v0.3.3

**응답 경과시간 표시와 대기 경험 개선**을 중심으로 한 공식 릴리스입니다. 사용자 실사용 검토 후 승인받았습니다.

### 주요 변경

- 답변 준비 중 경과시간을 표시하고 완료·실패 시 소요시간을 고정
- 각 답변의 시간을 독립적으로 유지하며 새 질문은 0부터 측정
- 질문 제출부터 화면 렌더링·페인트 기회까지의 브라우저 경과시간 사용
- 기존 검색·계층·근거·판정·답변 형식 유지
- 선행 임베딩 코드는 삭제하지 않되 **기본 OFF**로 보존
- 앱·정적 파일·검색 추적 버전 0.3.3 통일

### 사용자 경험

아무 변화 없이 기다리던 상태에서, 시스템이 작업 중임을 확인할 수 있는 대기로 개선했습니다. 시간만으로 문서 수나 데이터 문제를 판정하거나 검색 단계의 내부 진행률을 표시하지 않습니다.

### 확인 결과

- 자동 회귀·안전성 테스트 **84개 통과**
- 브라우저에서 진행·완료·실패 시간 표시 및 완료 후 타이머 정지 확인
- 소수 실제 비교에서 일반 질문의 동일 근거·판정 유지, 영상 목록 16건의 답변·인용 순서 동일성 확인
- 선행 임베딩은 검색어가 재작성된 사례에서 재사용되지 않아, 전체 응답시간 개선 효과를 입증하지 못했습니다. 추가 호출을 발생시키지 않도록 OFF로 유지합니다.
- **이번 릴리스는 정확도나 검색속도 개선을 주장하지 않습니다.** 대기 경험과 측정 가능성을 개선한 버전입니다.

### 운영·복구

일반 실행에서는 `SEARCH_EMBEDDING_PREFETCH=false`가 기본값입니다. 실험 재개는 별도 설정으로 가능하며, 응답시간 표시와 독립적입니다. 로컬 검토용 Dockerfile/compose 파일은 사전에 저장한 로컬 이미지가 필요하므로 신규 설치의 기본 빌드로 사용하지 않습니다.

이전 공식 태그 `v0.3.2`, 변경 전 코드 태그 `pb-before-embedding-prefetch-20261030`, 이전 로컬 실행 이미지를 보존했습니다. DB 스키마 변경은 없습니다. 실제 대화·측정 응답·인증 정보는 Git에 포함하지 않습니다.
