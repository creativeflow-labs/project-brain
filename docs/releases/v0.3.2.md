## Project Brain v0.3.2

영상 검색의 조건·집계·답변 경로 오류를 수정하고, Notion 계층 메타데이터를 포함한 키워드 검색의 반복 처리를 줄인 공식 릴리스입니다. 사용자 실사용 검토 후 배포를 승인받았습니다.

### 주요 변경

- 실전편 등 명시적인 제목 조건을 실제 필터로 적용하고 출력 제한 전에 집계
- 개수·목록·내용 설명 요청 분리: 내용 질문에도 전체 영상 목록이 반복되던 문제 수정
- 출력 상한 100건을 전체 개수로 단정하지 않도록 보완
- 여러 검색어가 같은 PostgreSQL 검색용 변환 결과를 요청 내부에서 공유
- 기존 Notion 계층 검색·점수·근거 확장·월별 영상 목록 유지
- DB 스키마·색인·원문·동기화·모델 변경 및 요청 사이 결과 캐시 추가 없음

### 확인 결과와 범위

- 자동 테스트 71개 통과
- 네 질문의 검색 후보 순서·계층 점수·근거 본문 동일
- 별도 PostgreSQL 키워드 후보 비교 3건 일치
- 동일 검색 계획·임베딩, 각 2회 비교의 검색 단계 중앙값:
  - 김그륜 바이브코딩: 6.675초 → 1.360초
  - SK 다이렉트 의사결정자: 7.026초 → 1.184초
- 전체 자료 검색과 월별 목록은 속도가 거의 동일했습니다.
- **위 수치는 검색 단계 기준입니다. 질문 입력부터 최종 답변 화면 노출까지의 시간은 미측정이며, 전체 응답시간이 같은 비율로 줄었다는 의미는 아닙니다.** 이후 개선에서는 전체 화면 노출 시간을 주 평가 기준으로 사용합니다.
- 모든 질문의 정확도 및 속도 개선을 보장하지 않습니다.

실제 질문·응답·임베딩·측정 원본·인증 정보는 Git 배포에서 제외합니다.
