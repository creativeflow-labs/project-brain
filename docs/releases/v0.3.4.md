# Project Brain v0.3.4

2026-11-20 · 로컬 검증용 코드 릴리스

## 변경 사항

- 네이버웍스 메시지는 프로젝트에서 지정한 대화와 기간을 수동으로 동기화해 검색 근거로 사용합니다. 본인 전용 PB 봇은 생성한 전송문과 근거를 보여주고, 사용자가 별도로 승인해야 발송합니다.
- 기록 목록·개수 요청과 본문 설명을 분리합니다. 같은 대화에서 동일한 목록 요청이 반복되면 이미 검증된 조건만 재사용하고 답변은 현재 색인에서 다시 구합니다.
- 목록 내 서로 다른 항목을 값 충돌로 처리하지 않도록 비교 기준을 보강했습니다. 근거가 부족한 경우 전체 목록이라고 단정하지 않습니다.

## 검증과 한계

- 자동 테스트 189개를 통과했습니다. 실제 자료로 목록·집계·본문 분기와 발송 승인 대기까지 표본 검증했으며, 이 릴리스 검증에서 메시지는 발송하지 않았습니다.
- 전체 질의의 정확도나 응답시간을 보장하지 않습니다. 팀 단위 발송, 자동 수신과 공개 운영 배포는 포함하지 않습니다.
- 인증 정보, 연결·동기화 상태 및 실제 사내 자료는 저장소에 포함되지 않습니다. 환경별 네이버웍스 조회 인증과 봇 발송 설정은 각각 확인해야 합니다.

## 롤백

- 이전 공식 코드는 `v0.3.3`입니다. 코드 태그는 DB·인증 설정·실행 이미지의 스냅샷이 아니므로 실행 환경 복구와 데이터 복원은 별도로 검증해야 합니다.
