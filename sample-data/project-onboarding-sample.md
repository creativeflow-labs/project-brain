# Creative Flow 프로젝트 온보딩

## 브랜드 철학

우리는 AI를 단순한 작업 단축 도구로 설명하지 않는다. 이전에 경험하지 못한 기술이 실제 업무와 삶에 안정적으로 안착하는 방법을 연구하고 교육한다. 기능의 화려함보다 사용자가 반복해서 신뢰할 수 있는 업무 흐름을 우선한다.

## 현재 프로젝트 방향

2026년 7월 21일 회의에서 Project Brain의 기본 단위를 회사 전체가 아닌 개별 프로젝트로 확정했다. 전사 자료를 모두 가져오면 정보가 무난해지고 관리 비용이 높아지기 때문이다. 첫 번째 MVP는 프로젝트 관리자가 선택한 자료만 연결한다.

## 시안 변경 결정

고객은 2026년 7월 22일 2차 시안을 거절했다. 거절 이유는 색상이 아니라 표현 방식이 핵심 고객인 30~40대 실무자의 기대보다 지나치게 가볍고, 타깃 연령대와 맞지 않았기 때문이다.

현재 확정된 방향은 A안이다. A안은 전문성과 안정성을 유지하되 설명 문구를 더 쉽게 수정한다. 최종 승인은 김민서 팀장에게 받아야 한다.

## 업무 원칙

- 확정되지 않은 제안을 결정된 사실처럼 공유하지 않는다.
- 고객 피드백에는 발생 날짜와 원본 출처를 함께 기록한다.
- 프로젝트 외부 자료를 임의로 가져오지 않는다.
- 근거가 없거나 충돌하면 추측하지 말고 담당자에게 확인한다.
