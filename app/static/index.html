CONNECTORS

데이터 연결

연결 권한 범위 안의 지식을 자동으로 발견하고 변경분만 동기화합니다.

W

네이버웍스

지정한 대화방·기간의 텍스트 메시지를 동기화하고 원문 근거로 검색합니다. 본인 전용 봇 전달은 채팅에서 전송문을 확인하고 승인한 뒤 실행합니다.

연결 전Lite 가입과 Developer Console 설정이 필요합니다.

읽기 전용 · 1회 최대 31일·10MB, 검색 적재 최대 1,000건. 재동기화 시 동일 메시지는 중복 저장하지 않습니다. 인증 정보는 암호화 저장하고 AI로 보내지 않으며, 동기화한 본문은 기존 PB 검색·AI 분석 흐름에 사용됩니다. 원본 링크는 웹 메신저를 열며 정확한 메시지는 대화방·시각으로 확인합니다.

N

Notion

페이지 주소를 입력하지 않아도 접근 가능한 페이지·데이터베이스와 지원 첨부파일을 자동으로 동기화합니다.

연결 상태 확인 중 현재 프로젝트의 Notion 연결을 확인하고 있습니다.

Notion Search API 특성상 계정 범위 탐색은 최선 노력 방식입니다. 동기화 결과와 누락 가능성을 상태에 표시합니다.

M

Gmail

이메일 본문과 PDF·DOCX·TXT·MD 첨부파일을 읽기 전용으로 동기화합니다.
